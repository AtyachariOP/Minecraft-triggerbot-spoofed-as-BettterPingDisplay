A [Fabric](https://fabricmc.net/) mod for Minecraft to display each player's ping in the player list as a number.

Go [**here**](https://github.com/vladmarica/better-ping-display) for the Forge/NeoForge edition of this mod.


This is a client-side mod. The server doesn't need to have it installed. It works even when playing on vanilla servers.

## Configuration
This mod's config file is `Modules`. It contains the following options:

| Option  | KeyBinds  | Description  |
|---|---|---|
| TriggerBot  | `B` | Automatically hit enemy when aiming on them (have natural hitting means no inhuman like trigger) |
| AutoJumpReset  | `J` | More logical + not 0 kb JumpReset (Mostly 80% kb reduced sometimes 100% kb reduction) |
| AutoPot  | `U`  | While hovering over pots it automatically takes pots from inventory to you hotbar slots |
